# Módulos

La ruta no depende de una clase en vivo. Cada módulo comienza con una pregunta, utiliza agentes para investigar y termina con algo construido o enseñado.

1. **Aprender** — ¿Qué son los grandes modelos de lenguaje?
2. **Investigar** — ¿Cómo encuentro, comparo y compruebo conocimiento con agentes?
3. **Construir** — ¿Qué puedo hacer con lo aprendido?
4. **Publicar** — ¿Cómo convierto mi trabajo en una URL?
5. **Enseñar** — ¿Cómo explico lo aprendido a otra persona?
6. **Multiplicar** — ¿Cómo dejo objetos de conocimiento que otros humanos y agentes puedan descubrir?
