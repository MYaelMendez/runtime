# Enseñar

Aquí vive la evidencia de **“Esto puedo enseñar.”**

Convierte al menos una cosa que aprendiste en un recurso para otra persona.

Puede ser:

- una explicación de 200 palabras;
- una imagen;
- un post;
- una mini-lección;
- una guía paso a paso;
- una página web;
- una demostración.

Regla:

> Si puedes explicarlo con claridad, mostrar cómo lo comprobaste y ayudar a otra persona a intentarlo, ya estás pasando de estudiante a docente.
