# Posts · Objetos de conocimiento

En este Diplomado, un post no es material complementario.

**El post puede ser la lección.**

`POST → AGENTE → HUMANO → PRAXIS → NUEVO POST ↺`

Usamos `#grandesmodelosdelenguaje` como índice semántico compartido para descubrir publicaciones, relacionarlas y convertirlas en nuevas preguntas y objetos de conocimiento.

Cada post de aprendizaje debe intentar responder:

- ¿Qué encontré?
- ¿Qué fuentes o publicaciones revisé?
- ¿Qué me explicó mi agente?
- ¿Qué comprobé yo?
- ¿Qué construí o hice con ello?
- ¿Cómo se lo explicaría a otra persona?
