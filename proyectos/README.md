# Proyectos

Aquí vive la evidencia de **“Esto construí.”**

Un proyecto puede ser pequeño:

- una página HTML;
- una guía;
- un prompt probado y documentado;
- una visualización;
- una automatización;
- una investigación;
- una herramienta;
- un objeto de conocimiento reutilizable.

Lo importante es documentar qué problema intentabas resolver, qué hiciste, qué aprendiste y qué podría aprender otra persona de tu trabajo.
