# Recursos

Material ligero para aprender desde cualquier lugar.

Principios:

- móvil primero;
- archivos pequeños;
- texto claro;
- enlaces directos;
- actividades asíncronas;
- ejemplos LATAM;
- posibilidad de aprender con baja conectividad;
- profundidad opcional para quien quiera seguir investigando.

**Accesibilidad no es una sección al final. Es la manera de enseñar.**
